# 需求说明目录

本目录记录每次本地更新的需求、验收标准、边界条件和不做事项。

## 约定

- 每次需求变更新增一个 `YYYY-MM-DD-主题.md` 文件，或在当天的既有文件中追加版本段落。
- 需求文档必须说明：背景、目标、验收标准、涉及模块、数据库/资产影响、敏感数据边界。
- 代码完成后必须在对应需求文档标记实现状态和验证结果。
- 版本摘要同步写入根目录 `CHANGELOG.md`。
